# Cilium

Talos applies `cilium.yaml` as the cluster CNI (`cluster.network.cni.urls`) at
bootstrap and again on every `talosctl upgrade-k8s`. Flux's `cilium`
HelmRelease manages the same objects, so the file must match what Flux
deployed, or `upgrade-k8s` rolls the DaemonSet and Deployments to a different
spec (and helm-controller then rolls them back).

## Regenerate after a Cilium upgrade

Render from the deployed release once Flux has rolled the new chart out. A
client-side `kustomize`/`helm template` render does not match: helm-controller
renders null chart defaults differently (e.g. an empty `--k8s-api-server-urls=`
arg) and labels pods `cilium-<version>_<oci-digest>`.

```bash
helm get manifest cilium -n kube-system \
  | yq 'select(.kind != null) | select((.kind == "Secret" and (.metadata.name == "cilium-ca" or .metadata.name == "hubble-relay-client-certs" or .metadata.name == "hubble-server-certs")) | not)' \
  > /tmp/cilium-release.yaml
{
  echo "# This manifest was generated by automation. DO NOT EDIT."
  echo "# Source: helm get manifest cilium -n kube-system (the Flux-deployed release),"
  echo "# minus the cilium-ca / hubble-*-certs Secrets. See README.md."
  cat /tmp/cilium-release.yaml
} > talos/integrations/cilium/cilium.yaml
```

Check before running `upgrade-k8s` — the DaemonSet and Deployments should
show no pod template changes:

```bash
kubectl diff --server-side --field-manager=talos --force-conflicts \
  -f talos/integrations/cilium/cilium.yaml
```

The TLS Secrets are excluded on purpose: this repo is public and they hold the
Cilium CA and Hubble private keys. helm-controller creates and owns them; the
agent's `hubble-server-certs` mount is optional, so bootstrap does not need
them.

## New cluster (no release to read yet)

`kustomization.yaml` renders the chart offline with the same values and also
drops the Secrets:

```bash
rm -rf talos/integrations/cilium/charts
kustomize build --enable-helm --load-restrictor=LoadRestrictionsNone \
  talos/integrations/cilium > /tmp/cilium-offline.yaml
```

Use that only to bootstrap; regenerate from the release once Flux owns Cilium.
